# FirstLine Builders Guide

How anyone at FirstLine Schools builds a tool: describe it to Claude, build it where it belongs
(usually Google or Claude), ask for GitHub only when it needs its own server, and check it before
others rely on it.

**Live:** https://firstline-schools.github.io/builders-guide/
**Owner:** Scott Shirey, Chief Innovation Officer

## Editing

The whole site is `index.html`. There is no build step.

- **Small text change:** open `index.html` on GitHub, click the pencil, edit, **Commit changes**.
  The site updates in about a minute.
- **Anything bigger:** open this repository in claude.ai/code and describe the change.

This repository is **public**. Never put student or staff information, passwords, or keys in it.
